# A shared teaching codebase outlived its rotating maintainers

Contributors have joined and stepped back since 2023, and the droidcon Kenya Android app still works as a shared teaching codebase. Volunteer apps rarely outlive their authors. This one went quiet for up to 211 days, tried Kotlin Multiplatform twice, and moved from Kotlin 1.8 to 2.4.

Contributors join by opening pull requests and step back when work gets busy, with no formal handover. The talk walks the git history era by era, tying each change to a commit and marking guesses as guesses.

Attendees leave with a checklist for keeping a shared codebase alive: keep docs as the way the next contributor picks up work, gate size and performance in CI, and record every reversal with its reason.

The talk covers repository history and the 2026 rebuild, not why contributors stepped back, which git does not record. Size and build figures come from commits, not device measurements.

**Level:** Intermediate
**Prerequisites:** Kotlin and Jetpack Compose basics; familiarity with Hilt and Room helps
**Format:** 45 minutes including Q&A; slides with screen recordings and screenshots
**Speakers:** Donald Isoe, Mobile Engineer at Terra and Community Organiser at Kotlin Kenya and Android 254, "professional spammer of Command + Click". Annunziata Kinya, Mobile Engineer at Cashia and Organiser at DroidconKE. Ian Nthuli, Mobile Engineer at NCBA Bank and Organiser at DroidconKE.
