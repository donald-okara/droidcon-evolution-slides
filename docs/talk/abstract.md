# A shared teaching codebase outlived its maintainers

The droidcon Kenya Android app has changed hands several times since 2023 and still works as a shared teaching codebase.

Volunteer apps rarely outlive their authors. This one went quiet for up to 211 days, tried Kotlin Multiplatform twice, and moved from Kotlin 1.8 to 2.4.

The talk walks through the git history era by era, tying each change to a commit and flagging reasons git cannot show as guesses. Three presenters share 45 minutes, slides only.

Attendees leave with a checklist for keeping a shared codebase alive: keep the docs as the handover, gate size and performance in CI, and record every reversal with its reason.

The talk covers repository history and the 2026 rebuild, not why maintainers changed, which git does not record. Size and build figures come from commits, not device measurements.

**Level:** Intermediate
**Prerequisites:** Kotlin and Jetpack Compose basics; familiarity with Hilt and Room helps
**Format:** 45 minutes including Q&A, slides only

**Speaker:** Presenter 1, Presenter 2, Presenter 3. Names, roles, and one line of relevant experience for each to follow.
